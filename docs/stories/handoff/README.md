# Puggle — One Boot / Storyboard & Interactive Dummy 01

**Created:** 16 November 2026  
**Stage:** Visual pacing, flap placement and world continuity. **Not an illustrated production book or native 3D build.**

## Start here

1. Open **`One_Boot_Storyboard_Review.pdf`** — a 15-page visual review with all 11 story openings, closed/reveal notes and a physical flap brief.
2. Open **`One_Boot_Interactive_Dummy.html`** in a browser **with its adjacent `assets/` and `concepts/` folders present**. This is a local offline HTML/CSS/SVG prototype, not Metal or RealityKit. Use **Previous / Next**, tap **Lift flap**, or click the flap itself; switch to Reader view to hide production notes. The optional highlight follows the pointer only; it is not device-attitude rendering.
3. Read **`specification/ONE_BOOT_DUMMY_DECISIONS.md`** for editorial implications and outstanding decisions.
4. Read **`specification/ONE_BOOT_MANUSCRIPT.md`** — exact author's original text, unchanged.
5. Read **`specification/REALITYKIT_CONTENT_CONTRACT.md`** and **`CLAUDE_NEXT_PROMPT.md`** to continue implementation in Claude Code.

## Technical caveats

- HTML was syntax-checked and asset references verified. Automated browser screenshots were prevented by this runtime's browser-access policy; please test manually in Safari/Chrome. There is no native app compiled in this bundle.
- The image-generation step for a fresh illustrated book mock-up failed. This package uses **existing creator-approved source sheets and previously generated concept environments** to make a structural dummy; it does not represent newly finished printed artwork.
- Page one and page ten include a **rough separate boot placeholder** over/near approved Puggle/Pebble cutouts. They must be redrawn as controlled wardrobe/prop layers before illustration approval.
